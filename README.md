# LIT — Letterboxd in Terminal

A retro-inspired, local-first movie logging app for the terminal.

## Setup

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Run

```bash
python lit/main.py
```
